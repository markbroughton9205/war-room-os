## GAPS (countries/regions lacking verified machine APIs as of 2026)
- Asia: Pakistan PBS, Bangladesh BBS, Sri Lanka DCS, Nepal CBS, Iran SCI, Mongolia NSO, Myanmar — no public API found (portal/xlsx only).
- Middle East: UAE FCSC, Qatar PSA, Jordan DoS, Kuwait CSB — portal-only; Saudi covered via national open-data portal.
- Latin America: Chile INE, Peru INEI, Ecuador INEC, Bolivia INE, Paraguay INE, Venezuela — no cell-level API (Socrata portals partially mitigate: Colombia yes; Chile/Peru datos abiertos portals exist but DANE-grade statistical APIs absent).
- Oceania: Pacific island NSOs (Fiji, PNG, Samoa...) — covered only via SPC SDD (sdd.spc.int, .Stat-based) — candidate for follow-up.
- Europe minor: Ukraine (Ukrstat — degraded by war), Belarus, Balkan NSOs beyond EU — not verified here.
- China NBS: biggest single-country gap — no official API at all.
- Census microdata: IPUMS (registered) remains the main harmonized route; most NSOs (India, Indonesia, Brazil) distribute microdata only via application/CD, not API.
