# STATUS NOTES (2026)

DISCONTINUED / DEGRADED:
- Copernicus Data Space: OpenSearch (resto) Catalogue API decommissioned 2 Feb 2026; legacy STAC endpoint catalogue.dataspace.copernicus.eu/stac deprecated 17 Nov 2025 → new https://stac.dataspace.copernicus.eu/v1/. (Old SciHub closed Oct 2023.)
- Met Office DataPoint: retired 1 Dec 2025. No like-for-like replacement; Weather DataHub covers site forecasts/obs + map images; regional text forecasts & daily extremes now web-only (GAP).
- JMA XML PUSH distribution ended 2020; several legacy warning telegram codes end ~2028 (migration to VPWW55–61 series).
- ECMWF legacy CDS decommissioned Sep 2024; cds-beta URL also dead — must use cds.climate.copernicus.eu/api + cdsapi ≥0.7.7.
- JAXA G-Portal: FTP disabled (SFTP only); service relaunched 1 Apr 2025 after extended 2024 outage.
- CelesTrak: 5-digit NORAD catalog exhaustion ~Jul 2026 — TLE format unavailable for catalog numbers ≥100000; adopt OMM (XML/KVN/JSON/CSV) parsing now.
- Space-Track: legacy tle/tle_latest/omm request classes deprecated → use `gp` class.
- NASA Exoplanet Archive: legacy nstedAPI being phased out → TAP.

TOP GAPS:
1. China (CNSA/CLEP): Lunar & Planetary Data Release System (moon.bao.ac.cn / clpds.bao.ac.cn) is SEARCH INTERFACE + download only — no documented API; needs account, Chinese-language UI. FengYun meteorological data (data.nsmc.org.cn) similar: portal-only, registration required.
2. Russia: Roscosmos/RosHydromet EO & weather — no open machine APIs found; GLONASS precise orbits via IAC FTP (semi-public). KRAS/Russian gazetteer gaps.
3. Africa: no operational African national mapping/EO API identified (African Regional Data Cube = web sandbox); SANSA EO portal limited. Rely on OSM/Overture/Copernicus.
4. Middle East: UAE/KSA national geoportal APIs not verified; Saudi NSG portal is UI-only so far.
5. Sentinel Asia (JAXA) — data access is web-UI/request-based for emergency members only; no public API.
6. ZTF/LSST transient alert streams: machine access exists via brokers (ANTARES, AMPEL, Fink — Kafka streams, registration) — worth a dedicated follow-up verification pass (not fully verified this session).
7. India: Bhuvan WMS layer inventory undocumented; no official STAC. MOSDAC (Indian meteorological sat) — portal-only.
8. Real-time seismic/feeds out of scope here (registry 12 likely).
9. IRSA & HEASARC (NASA/IPAC + HEASARC Browse) — both have TAP/REST interfaces (irsa.ipac.caltech.edu/TAP; HEASARC xamin TAP) verified only via astroquery references this session, not primary docs — candidate additions for wave 3.
