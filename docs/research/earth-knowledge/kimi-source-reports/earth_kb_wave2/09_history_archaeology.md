2. **South Asia**: no national newspaper/book API (NDLI undocumented; Digital Library of India fragmented; no Indian newspaper-archive API). GRETIL/SARIT cover premodern texts only.
3. **China (modern press)**: Shenbao/People's Daily etc. all commercial (East View/Duxiu/CADAL), no open APIs. Premodern covered (CText, CBETA, Kanripo, CBDB, CHGIS).
4. **Russia/CIS**: NЭB (rusneb.ru), Presidential Library (prlib.ru), Runivers — no documented public APIs found (unverified probes); East View holds newspaper archives commercially.
5. **Middle East/Arabic press**: Al-Ahram etc. commercial via East View; no national Arabic newspaper API found. QDL (IIIF) covers Gulf records; OpenITI covers premodern texts.
6. **Korea/Japan modern press**: Korean dynastic DBs are search interfaces (cross-ref wave2/16); Naver News Library commercial. Japan well covered via NDL/Japan Search (registered).
7. **Paleoanthropology-specific**: no dedicated hominin fossil/occurrence API found (NESPOS search interface; Smithsonian Human Origins no API). PBDB (registered) is the closest; radiocarbon via IntChron/p3k14c (registered). Gap for a curated hominin-sites layer.
8. **National archaeological site registers** (UK HERs, Canmore, Heritage Gateway, national monuments services): mostly no public APIs; ARIADNE (A3) is the aggregation workaround.
9. **World-history event/timeline datasets**: beyond Seshat/Cliopatria and Wikidata, no open machine-readable global event/timeline infrastructure verified (GeaCron commercial w/o open API; Running Reality unverified).
10. **Old Bailey Online / Founders Online / Documenting the American South**: US primary-source sites with reported downloads — unverified this session; candidate follow-ups.
