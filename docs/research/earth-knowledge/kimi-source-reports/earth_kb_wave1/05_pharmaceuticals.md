## GAPS & STATUS NOTES (searched, no machine access / not verified)
- **EUDAMED** (EU devices, Tier A): public site `ec.europa.eu/tools/eudamed` = SEARCH INTERFACE only; no public REST API verified. 4 modules (Actor, UDI/Device, NB-Certificates, Market Surveillance) MANDATORY since 28 May 2026 (Decision (EU) 2025/2371); DTX XML/XSD services exist for registered economic operators, not public read access. Vigilance module planned mandatory ~Q2 2027. Candidate `WARROOM_EUDAMED_URL` pending API publication.
- **Drug Interaction Knowledge Base (DIKB)**: academic/static, no maintained API found — superseded by RxNav Interaction API (free) / DrugBank DDI (paid).
- **PMDA Japan**: PMDA website + English "Reviews" pages = SEARCH INTERFACE; no public API verified. JADER (Japan ADR database) web-search only. India **CDSCO**: portal-only, no API. China **NMPA**: database search pages only. **MHRA (UK)**: Products website search; no official API. Recommend gaps list for future scraping-permission review.
- **WHO Prequalification of Medicines**: website + PDF/Excel listings; no API verified.
- **Withdrawn drugs**: no dedicated open API — best machine sources are EMA medicines dataset (withdrawn/refused status), DrugCentral `withdrawn` flags, ChEMBL `drug_warning` endpoint, FDA "Drug Safety Communications" RSS/FEED, and Discontinued Drug Product List in the FDA NDC/Drugs@FDA data.
- **EudraVigilance** public data: adrreports.eu = SEARCH INTERFACE (aggregate), no public API.
- **Pricing/access**: no global open drug-pricing API verified (MSH/HAI and national formularies are PDF/web); WHO MiND is web-only — flagged as gap.
- **Licensing caution summary**: PubChem/openFDA/NLM = public domain (freest); ChEMBL **CC BY-SA 3.0**, DrugCentral & PharmGKB **CC BY-SA 4.0** (share-alike propagates into derived KG distributions); GtoPdb share-alike (ODbL per third-party listing — confirm); DrugBank proprietary; VigiAccess © WHO/UMC restricted.

**Verification method**: all endpoints, rate limits, licenses and 2026 statuses confirmed via official docs (pubchem.ncbi.nlm.nih.gov, open.fda.gov, chembl.gitbook.io, EMA pages, EC EUDAMED overview, vaers.hhs.gov, health-products.canada.ca API guide, PharmGKB/ClinPGx policy pages, fda.gov Orange Book page) during this session.
