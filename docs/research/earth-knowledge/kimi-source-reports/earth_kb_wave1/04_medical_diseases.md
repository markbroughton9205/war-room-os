## STATUS NOTES (no/limited machine access — verified)
- **Radiopaedia** (Australia): NO official public API. Third-party wrappers exist (unofficial). Content CC-BY-NC-SA for articles but images restricted — treat as search interface; contact for licensing.
- **MSD Manuals (Merck Manuals)**: no public API; syndication/licensing only via commercial agreement.
- **NHS (UK) content**: NHS website content API was retired; syndication now via NHS.UK widgets/partnership — no open REST API verified in 2026.
- **GARD (NIH/NCATS)**: rarediseases.info.nih.gov — site operational, relaunched 2025; SEARCH INTERFACE only, no public API. Use Orphanet (#14) + RDAS (rdas.ncats.nih.gov, Neo4j browser, research-grade) instead.
- **jRCT (Japan)**: jrct.mhlw.go.jp — official registry, search interface only, no API; reach via ICTRP crawl (#5). Same for ChiCTR, CTRI (India), CRiS (Korea).
- **CIAP (Australia)**: NSW Health intranet clinical resource — no public access at all. Australian alternative: ADHA syndication Atom feed for SNOMED CT-AU/AMT releases (free clinician registration, digitalhealth.gov.au).
- **BioCaster (Japan, NII)**: research system, effectively dormant — do not rely on.

## GAPS & WARNINGS
1. **Migrations in flight (2026)**: PMC OA distribution (legacy FTP/OA API retired ~Aug 24, 2026 → AWS restructure) and WHO GHO OData endpoint deprecation — pin integration work after cutover or build adapters for both.
2. **No open symptom/diagnostic-knowledge API exists at authority level**: Infermedica (PL) and Isabel are commercial (tier D); OpenFDA `drug/event` + NLM ClinicalTables + MedlinePlus Connect are the closest free machine-readable substitutes.
3. **Imaging findings**: no free official API (Radiopaedia closed; RadLex via BioPortal only).
4. **Guidelines beyond UK**: WHO guidelines (IRIS repository — REST/OAI-PMH at iris.who.int, worth a future mission), USPSTF, and most national guideline bodies (US, DE, JP, IN) lack APIs.
5. **Surveillance paywall trend**: ProMED's 2025 shift to paid subscriptions breaks the historically free outbreak-feed ecosystem — budget or fall back to WHO EIOS (restricted) / RSS of national CDCs / GISAID.
6. **China/India/Japan medical literature**: CNKI (China) and Ichushi-Web (Japan) have no open APIs (commercial); J-STAGE (Japan) and IndMED/medIND (India) offer OAI-PMH/RSS — recommended as follow-up targets for regional coverage.
