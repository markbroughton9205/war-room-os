# DOMAIN 6 — TRADITIONAL & INDIGENOUS MEDICINE: Machine-Accessible Knowledge Sources (verified as of 2026)

**Verification method:** direct HTTP probing of every endpoint (curl), browser rendering where bot-blocked (Kew), official docs/news. Status codes cited below are from live probes this session.

**Evidence-classification preservation note (mission-critical):** Each block flags its evidence scheme: `TRAD` = recorded traditional use / pharmacopoeia record (NOT clinical proof); `EXP` = experimental/literature bioactivity; `PRED` = computational prediction (e.g., target inference); `NOMEN` = nomenclatural only; `CLIN` = clinical. War Room must never flatten TRAD/PRED records into clinical evidence.

## Gaps
1. **No open machine-readable API exists for codified Ayurvedic formulations** — TKDL is NDA-gated; IMPPAT is the open surrogate.
2. **Amazonian / indigenous South American medicine**: no verified structured database with API; records live in ethnopharmacology journals (→ suggest PubMed/Europe PMC + SciELO ingestion).
3. **African traditional-use records** beyond PROTA/SANCDB (e.g., PRELUDE, national pharmacopoeias) are PDF/search-only — no APIs found.
4. **Russian/Central Asian & Arabic/Unani (Greco-Arab) digitized corpora** exist only as manuscripts (Wellcome/BHL IIIF) — no structured APIs.
5. PFAF/UTP/NAEB/SymMap/TCMSP/ETCM are single-host fragile academic sites — recommend immediate bulk mirroring where licenses permit; NAEB's broken TLS is a warning sign.
