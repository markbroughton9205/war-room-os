- **libraries.io**: ALIVE (verified site visit). Free API w/ account, 60 req/min. Tidelift is being acquired by Sonar (banner live) — watch for changes. Vulnerability data now paywalled behind Tidelift; data is scraped/unvalidated.
- **Snyk**: not verified via official docs in this session — do NOT list as integration-ready. Known facts to re-verify: API at api.snyk.io (docs: apidocs.snyk.io), token auth, free tier exists; vuln DB API is largely commercial. **Treat as gated/commercial; verify before wiring.**
- **pyup/Safety DB**: partially verified — `safety` CLI pivoted to Safety Platform API (data.safetycli.com); legacy open safety-db repo (github.com/pyupio/safety-db) still exists but the premium CVSS data is paid. **Freemium, Tier D — low priority vs OSV.**

## GAPS & NOTES
1. **No source found for true "breaking changes / regression knowledge"** beyond issue trackers + deps.dev graphs. Renovate data (Renovate) and changelog aggregation have no public API; semver-compat datasets are academic only. This remains a genuine infrastructure gap.
2. RustSec advisory-db (github.com/RustSec/advisory-db, git clone, CC0) and PyPA advisory-database (github.com/pypa/advisory-database, CC-BY-4.0) exist as free git repos but are fully mirrored into OSV — integrate via OSV unless ecosystem-specific depth needed.
3. MITRE cvelistV5 git repo (github.com/CVEProject/cvelistV5) = cheapest bulk CVE mirror; cveawg.mitre.org API is CNA-workflow oriented — recommended as bulk backfill, NVD for query.
4. Non-US coverage note: this domain is inherently US-vendor-dominated; regional additions worth a follow-up: JVN (Japan, jvn.jp RSS/API), CNVD/CNNVD (China, no open API), CERT-FR/ANSSI JSON advisories (cert.ssi.gouv.fr — open JSON feeds), BSI CERT-Bund (Germany), CIRCL Vulnerability-Lookup (Luxembourg, open API) if War Room needs non-English advisory corpora.
