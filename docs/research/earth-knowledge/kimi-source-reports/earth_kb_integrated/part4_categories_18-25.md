### Category notes

#### REGIONAL COVERAGE SUMMARY (preserved from wave-2 file 16)
- **East Asia**: STRONG — Japan Search (national LOD graph), data.go.kr (huge API catalog), CBDB+CHGIS (China historical DH), Aozora (bulk), NCPSSD (free soc-sci). China mainstream scholarly (CNKI/Wanfang) remains API-closed.
- **South Asia**: MODERATE — Shodhganga OAI-PMH + data.gov.in verified but geo-blocked from sandbox; GRETIL excellent bulk. Indian Culture Portal (indianculture.gov.in) unreachable/no published API.
- **Middle East/Arabic**: WEAK machine access — Shamela bulk only; QDL IIIF but anti-bot; Ottoman Devlet Arşivleri has no API (search portal only, no verification achieved).
- **Latin America**: STRONG metadata infrastructure — LA Referencia + CLACSO OAI-PMH + DOAB harvest covers the region; AILLA for indigenous languages.
- **Russia/CIS**: WEAK — CyberLeninka/eLibrary live but no APIs; no open machine layer found.
- **Oceania/Pacific**: STRONG for language/culture (PARADISEC OAI, DigitalNZ API); Trove cross-ref.
- **Arctic**: STRONG — Arctic Data Center/DataONE REST + ONC Oceans 3.0 + GVP/NCEI mirrors.
- **Indigenous/endangered languages (global)**: STRONG discovery layer (OLAC in transition, PARADISEC, Pangloss, AILLA) + unique governance layer (Local Contexts API).
- **Specialized/rare**: STRONG — live-verified: OpenSky, SatNOGS, xeno-canto v3, Movebank, LibriVox, Gutenberg/Gutendex, Standard Ebooks, DOAB, OurAirports, Mushroom Observer, Wildlife Insights, GVP, Local Contexts.

#### GAPS / NOTES FOR LEAD (preserved from wave-2 file 16)
1. OLAC mid-migration (2025/26 rebuild) — re-verify after v2 relaunch.
2. xeno-canto v2 DISCONTINUED → v3 key-only (breaking change for existing integrations).
3. China: CNKI, Wanfang, CQVIP, NSSD all lack public APIs; NCPSSD is best free alternative. NGDC/CNCB (genomics) live [PROBE 200] but no documented public REST API — FTP/web bulk only; assigned to genomics agent for depth.
4. Geo-blocking observed: Shodhganga, data.gov.in, indianculture.gov.in, contents.koreanhistory.or.kr unreachable from sandbox egress — verify from in-region node before integration.
5. Russian-language machine access is the biggest structural gap: no OAI/API from CyberLeninka/eLibrary/RSL; may require partnership or permitted scraping.
6. Arabic/Ottoman: QDL blocks automation; Devlet Arşivleri (catalog.da.gov.tr) has no API — second structural gap.
7. Japanese national aggregator (Japan Search) bot-blocks datacenter IPs (403) — needs browser-like client or Japanese egress.
