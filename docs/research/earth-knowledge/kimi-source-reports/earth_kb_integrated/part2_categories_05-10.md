### STATUS NOTES (no/limited machine access — verified)
- **Radiopaedia** (Australia): NO official public API. Third-party wrappers exist (unofficial). Content CC-BY-NC-SA for articles but images restricted — treat as search interface; contact for licensing.
- **MSD Manuals (Merck Manuals)**: no public API; syndication/licensing only via commercial agreement.
- **NHS (UK) content**: NHS website content API was retired; syndication now via NHS.UK widgets/partnership — no open REST API verified in 2026.
- **GARD (NIH/NCATS)**: rarediseases.info.nih.gov — site operational, relaunched 2025; SEARCH INTERFACE only, no public API. Use Orphanet (#7 above) + RDAS (rdas.ncats.nih.gov, Neo4j browser, research-grade) instead.
- **jRCT (Japan)**: jrct.mhlw.go.jp — official registry, search interface only, no API; reach via ICTRP crawl (#5). Same for ChiCTR, CTRI (India), CRiS (Korea).
- **CIAP (Australia)**: NSW Health intranet clinical resource — no public access at all. Australian alternative: ADHA syndication Atom feed for SNOMED CT-AU/AMT releases (free clinician registration, digitalhealth.gov.au).
- **BioCaster (Japan, NII)**: research system, effectively dormant — do not rely on.

### GAPS & WARNINGS
1. **Migrations in flight (2026)**: PMC OA distribution (legacy FTP/OA API retired ~Aug 24, 2026 → AWS restructure) and WHO GHO OData endpoint deprecation — pin integration work after cutover or build adapters for both.
2. **No open symptom/diagnostic-knowledge API exists at authority level**: Infermedica (PL) and Isabel are commercial (tier D); OpenFDA `drug/event` + NLM ClinicalTables + MedlinePlus Connect are the closest free machine-readable substitutes.
3. **Imaging findings**: no free official API (Radiopaedia closed; RadLex via BioPortal only).
4. **Guidelines beyond UK**: WHO guidelines (IRIS repository — REST/OAI-PMH at iris.who.int, worth a future mission), USPSTF, and most national guideline bodies (US, DE, JP, IN) lack APIs.
5. **Surveillance paywall trend**: ProMED's 2025 shift to paid subscriptions breaks the historically free outbreak-feed ecosystem — budget or fall back to WHO EIOS (restricted) / RSS of national CDCs / GISAID.
6. **China/India/Japan medical literature**: CNKI (China) and Ichushi-Web (Japan) have no open APIs (commercial); J-STAGE (Japan) and IndMED/medIND (India) offer OAI-PMH/RSS — recommended as follow-up targets for regional coverage.

### SUPPLEMENTARY / STATUS NOTES (verified, not full blocks)

- **Expression Atlas (EMBL-EBI, incl. Single Cell Expression Atlas)** — programmatic access exists via JSON endpoints under https://www.ebi.ac.uk/gxa/json/... and FTP bulk (ftp.ebi.ac.uk/pub/databases/microarray/data/atlas/), but public API documentation is sparse/legacy (old /gxa/api retired). Classify as REST (lightly documented) + BULK. Tier A. Difficulty MODERATE. Verify endpoints before integration.
- **HMDB (Human Metabolome Database, Canada)** — ⚠ NO public REST API. Downloads at hmdb.ca/downloads (XML/SDF/FASTA/CSV) free for academic use; commercial use requires permission; API access only by contacting the team. Classify as BULK DOWNLOAD (registration/license-gated). Tier B. Do not promise an HMDB API connector.
- **DepMap (Broad Institute)** — ⚠ No stable documented public REST API (portal /api/ paths undocumented; may 404). Supported programmatic path: release matrices on Figshare via Figshare API (https://api.figshare.com/v2/articles/{id}) + https://depmap.org/portal/api/download/files table endpoint for current-release URLs. Classify as BULK DOWNLOAD via third-party REPOSITORY API. Tier A data. Env: `WARROOM_DEPMAP_FIGSHARE_ARTICLE_ID`.
- **ProteomeXchange announcement feed** — RSS: http://groups.google.com/group/proteomexchange/feed/rss_v2_0_msgs.xml + ProteomeCentral PX XML per dataset (http://proteomecentral.proteomexchange.org). Useful as FEED connector for new proteomics datasets.
- **QuickGO** (www.ebi.ac.uk/QuickGO/api) — complementary REST API specifically for GO *annotations* (gene–term associations), which OLS4 does not serve. Recommend as add-on to source #13 (cross-referenced in Category 05).

### GAPS & CAVEATS
1. **KEGG legal gap**: No free bulk access; budget for academic FTP subscription or substitute Reactome/WikiPathways for open pipeline use. Commercial War Room use requires Pathway Solutions license.
2. **No high-quality open CRISPR-perturbation REST API**: DepMap is download-only; BioGRID ORCS REST covers literature screens (key required). LINCS CLUE API (clue.io, free academic key) exists for perturbational signatures but was out of scope to fully verify — flag for a future mission.
3. **Regional coverage**: INSDC triad covered (NCBI/ENA/DDBJ). No equivalent open APIs found for China (NGDC/CNCB — BIG Data Center offers genome databases with some APIs; NGDC GSA largely mirrors INSDC but API documentation is thin/Chinese-language — candidate for a dedicated Asia mission), Russia (no major open molbio API), Africa/Latin America (rely on INSDC mirrors; H3Africa data is largely controlled-access via EGA).
4. **Rate-limit transparency**: Only NCBI, Ensembl, ENA publish hard limits; most others are "fair use" — implement client-side throttling (≤2–10 req/s) and respect Retry-After.
5. **Migration watch items for 2026**: Ensembl platform migration (beta.ensembl.org) may alter REST surface; OLS3→OLS4 completed but old `/ols/api` URLs should be updated to `/ols4/api`; NCBI Datasets v1 deprecated.

### STATUS NOTES ON OTHER MISSION ITEMS
- **Extinct organisms**: covered via IUCN v4 (EX/EW categories), PBDB (`extant=false`, deep time), BirdLife (Possibly Extinct flags). No standalone extinct-species API exists.
- **Ecosystems/biomes**: IUCN Global Ecosystem Typology (https://global-ecosystems.org, 200 ✓) offers profile pages + GIS/CSV downloads (no REST API); WWF Terrestrial Ecoregions via GIS downloads. Flagged as MODERATE bulk-only sources — recommend a future dedicated probe.
- **CABI Invasive Species Compendium**: rich dossiers but gated/commercial, no public API — use GRIIS instead.
- **Protists**: beyond BacDive/LPSN (prokaryotes), eukaryotic protists covered by WoRMS (AlgaeBase-linked) and IRMNG (same Aphia REST platform — `https://www.irmng.org/rest/...`), live in 2026.

### GAPS NOTE
No public machine API for: BirdLife (request-gated), POWO (unofficial/bot-blocked), Index Fungorum (legacy SOAP only), TRY (manual request cycle), BGCI tools (CSV only), ICTV (spreadsheet only). Ecosystem/biome data lacks a unified REST API globally. Regional/global coverage is heavily Europe/US-centric for infrastructure; Asian nodes exist mainly as GBIF national nodes rather than standalone APIs (China's CVH/NSII, Japan's J-IBIS/S-Net, India's IBP are web portals without documented public REST APIs — verification recommended as a follow-up mission). Rate limits are unpublished for most open biodiversity APIs; plan conservative pacing (≤1 req/s) except NCBI (3–10/s) and iNaturalist (60/min).
