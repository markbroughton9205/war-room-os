### Category notes

From file 12 "STATUS NOTES (2026)" — weather/climate-relevant items:

- Met Office DataPoint: retired 1 Dec 2025. No like-for-like replacement; Weather DataHub covers site forecasts/obs + map images; regional text forecasts & daily extremes now web-only (GAP).
- JMA XML PUSH distribution ended 2020; several legacy warning telegram codes end ~2028 (migration to VPWW55–61 series).
- ECMWF legacy CDS decommissioned Sep 2024; cds-beta URL also dead — must use cds.climate.copernicus.eu/api + cdsapi ≥0.7.7.

From file 12 "TOP GAPS" — weather/climate-relevant items:

- China: FengYun meteorological data (data.nsmc.org.cn) portal-only, registration required, no documented API.
- India: MOSDAC (Indian meteorological sat) — portal-only.
- Met Office daily extremes / regional text forecasts lost API access entirely with DataPoint retirement.
- Real-time seismic/feeds were out of scope of file 12 (noted there as likely belonging to this registry category).

**Environmental-data blind spot (mission-level gap):** no UNEP, US EPA, or European Environment Agency (EEA) machine APIs were verified in this mission's wave-2 reports — air/water quality, emissions, and environmental-indicator data currently have no verified dedicated environmental-agency API in this registry; nearest partial coverage is Open-Meteo air-quality model data, ECMWF CAMS (ADS), and Met.no LUFT endpoints above. Priority follow-up category for the next wave.
