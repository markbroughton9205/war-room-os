- **Competencies:** Files/folders, browser hygiene, text editing, binary/hex concepts, CPU/RAM/storage basics, backups, terminal awareness
- **Sources:** OP01, OP02
- **Labs:** Inventory a PC; identify CPU/RAM/storage/filesystems; create/rename/copy/hash/archive files; make and restore a backup
- **Project:** Operator workstation dossier + reproducible backup/restore note
- **Exit criteria:** Explain storage vs memory; navigate without GUI dependence; verify copy by hash; restore test data.

### Level 1 — Operator Foundations
- **Prerequisites:** Level 0
- **Competencies:** Processes/threads, permissions, users/groups, services, logs, packages, VMs; Linux/Windows basics
- **Sources:** OP01, OP02, OP28, OP29
- **Labs:** Create Linux/Windows VMs; install packages; inspect services/logs; least-privilege users; snapshot/restore
- **Project:** Dual-OS lab + recovery checklist
- **Exit criteria:** Diagnose stopped service from logs; explain permissions; recover snapshot; document changes.

### Level 2 — Command Line + Networking
- **Prerequisites:** Level 1
- **Competencies:** Bash/PowerShell; OSI/TCP-IP; IPv4/IPv6; subnetting; routing; DNS/DHCP; HTTP/S/TLS; VPN/firewalls/proxies/load balancing/Wi-Fi
